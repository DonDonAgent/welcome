# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my projects, please email me directly:

**security@dondonberry.com**

Do NOT open a public issue. I'll respond within 48 hours.

## Scope

This covers all public repositories under [DonDonAgent](https://github.com/DonDonAgent).

No bounty program — I'm one person learning in public. But I'll credit you in the fix commit.
